## **1. Event-Driven Workflow Architecture**

### **Core Principle: React to Events, Not Time**

```
EVENT-DRIVEN FLOW:

1. Event Detection → 2. Event Enrichment → 3. Risk Assessment → 
4. Decision Making → 5. Action Execution → 6. Validation → 7. Feedback Loop

No cron jobs. All triggers are event-based.
```

## **2. Component-by-Component Logic**

### **Component 1: Event Collectors (Data Ingestion)**

#### **A. AWS Spot Advisor Scraper**

```python
"""
Spot Interruption Data Scraper
Purpose: Continuously scrape AWS Spot Advisor and emit events
"""

Logic Flow:

1. INITIALIZATION:
   - Load scraping config (regions, instance types to monitor)
   - Connect to Event Bus
   - Initialize last known interruption rates cache
   
2. SCRAPING LOOP (Event-Driven, not polling):
   
   Trigger: AWS CloudWatch Event for Rebalance Recommendation
   OR
   Trigger: Scheduled Lambda (every 5 minutes as fallback)
   
   Process:
   a. Scrape AWS Spot Advisor:
      url = "https://spot-bid-advisor.s3.amazonaws.com/spot-advisor-data.json"
      data = fetch(url)
      
   b. Parse interruption rates:
      FOR each (region, instanceType) in data:
        currentRate = data[region][instanceType]["interruptionRate"]
        previousRate = cache.get(region, instanceType)
        
        IF currentRate != previousRate:
          # Rate changed - emit event
          delta = currentRate - previousRate
          
          IF delta > 0.05:  # 5% increase threshold
            EMIT EVENT:
              type: "spot.risk.increased"
              payload: {
                region: region,
                instanceType: instanceType,
                previousRate: previousRate,
                currentRate: currentRate,
                delta: delta,
                timestamp: now()
              }
          
          # Update cache
          cache.set(region, instanceType, currentRate)
   
   c. Check for regional patterns:
      IF multiple instance types in same AZ showing increases:
        EMIT EVENT:
          type: "spot.regional.risk"
          payload: {
            region: region,
            availabilityZone: az,
            affectedTypes: [...],
            pattern: "capacity_crunch",
            severity: "high"
          }

3. AWS EC2 REBALANCE RECOMMENDATION HANDLER:
   
   Trigger: AWS EventBridge Rule for EC2 Rebalance Recommendations
   
   EventBridge Rule:
   {
     "source": ["aws.ec2"],
     "detail-type": ["EC2 Spot Instance Interruption Warning"],
     "detail": {
       "instance-id": [...]
     }
   }
   
   Handler Logic:
   a. Receive interruption warning from AWS
   b. Enrich with cluster context:
      - Query K8s API: Which node is this instance?
      - What pods are running on this node?
      - What's the pod priority distribution?
   
   c. EMIT EVENT:
      type: "spot.interruption.imminent"
      payload: {
        instanceId: event.detail.instanceId,
        nodeName: k8s.getNodeForInstance(instanceId),
        timeToInterruption: "2 minutes",
        podsAffected: [...],
        priority: "CRITICAL"
      }

4. GLOBAL INTERRUPTION AGGREGATOR:
   
   Purpose: Learn from interruptions across ALL client clusters
   
   Logic:
   a. Receive interruption events from all client clusters
   b. Store in time-series database:
      schema:
        timestamp, clientId, region, az, instanceType, 
        interruptionType (spot_reclaimed, rebalance_recommendation)
   
   c. Analyze patterns (every 1 minute):
      - Group by (region, instanceType, 1-hour window)
      - Count interruptions
      - Calculate statistical anomalies
      
      IF interruptions > (mean + 2*stddev):
        EMIT EVENT:
          type: "spot.global.interruption.spike"
          payload: {
            region: region,
            instanceType: instanceType,
            interruptionCount: count,
            confidenceLevel: 0.95,
            affectedClients: clientIds,
            recommendation: "avoid_this_pool_for_next_hour"
          }
   
   d. Flag risky pools:
      riskRegistry.markPool(
        region=region,
        instanceType=instanceType,
        riskLevel="high",
        expiresAt=now() + 1hour
      )
```

#### **B. Kubernetes Watchers**

```python
"""
Kubernetes Event Watchers
Purpose: Watch K8s API for relevant events and emit to Event Bus
"""

Watcher 1: Pod Event Watcher

Logic:
1. Watch Pod events with filters:
   kubectl get events --watch --field-selector involvedObject.kind=Pod
   
2. Filter for specific events:
   - Evicted (reason: spot interruption)
   - OOMKilled
   - Failed scheduling
   - CrashLoopBackOff
   
3. Enrich and emit:
   FOR each event:
     IF event.reason == "Evicted" AND event.message.contains("spot"):
       pod = k8s.get_pod(event.podName)
       node = k8s.get_node(pod.spec.nodeName)
       
       EMIT EVENT:
         type: "pod.evicted.spot"
         payload: {
           podName: event.podName,
           namespace: pod.namespace,
           nodeName: node.name,
           nodeInstanceType: node.labels["node.kubernetes.io/instance-type"],
           spotPool: node.labels["karpenter.sh/nodepool"],
           priorityClass: pod.spec.priorityClassName,
           restartCount: pod.status.containerStatuses[0].restartCount
         }

Watcher 2: Node Event Watcher

Logic:
1. Watch Node status changes:
   k8s.watch(kind="Node")
   
2. Detect state transitions:
   FOR each node event:
     IF node.status.conditions["Ready"] == False:
       EMIT EVENT:
         type: "node.not.ready"
         payload: {
           nodeName: node.name,
           instanceType: node.labels["node.kubernetes.io/instance-type"],
           reason: node.status.conditions.reason,
           spotPool: node.labels["karpenter.sh/nodepool"]
         }
     
     IF node.status.conditions["DiskPressure"] == True:
       EMIT EVENT:
         type: "node.disk.pressure"
         payload: {...}

Watcher 3: Pending Pods Watcher

Logic:
1. Watch for pods stuck in Pending state:
   
   Trigger: Pod creation event
   
   Process:
   a. Start timer when pod becomes Pending
   b. Check after 30 seconds:
      IF pod still Pending:
        reason = pod.status.conditions.reason
        
        IF reason contains "Insufficient cpu|memory":
          EMIT EVENT:
            type: "capacity.insufficient"
            payload: {
              requiredCpu: pod.spec.containers[].resources.requests.cpu,
              requiredMemory: pod.spec.containers[].resources.requests.memory,
              nodeSelector: pod.spec.nodeSelector,
              tolerations: pod.spec.tolerations
            }
```

#### **C. DaemonSet Metrics Collector**

```python
"""
DaemonSet running on every node
Purpose: Collect node-level metrics and emit events for anomalies
"""

DaemonSet Logic (runs on each node):

1. INITIALIZATION:
   - Get node information (name, instance type, spot pool, labels)
   - Connect to Event Bus
   - Initialize metrics buffers (rolling windows)

2. METRICS COLLECTION LOOP:
   
   Interval: Every 10 seconds (local collection, not event emission)
   
   Collect:
   a. CPU utilization (from cgroups)
   b. Memory utilization (from /proc/meminfo)
   c. Disk I/O (from /proc/diskstats)
   d. Network throughput (from /proc/net/dev)
   e. Pod count on node
   f. Container restart counts
   
   Store in sliding window: last 6 data points (1 minute of data)

3. ANOMALY DETECTION (Event Emission):
   
   Run analysis every 30 seconds on collected metrics
   
   Detection Rules:
   
   Rule 1: Sustained Underutilization
   IF avg(cpu_utilization, last_1min) < 20% AND
      avg(memory_utilization, last_1min) < 30% AND
      duration > 5 minutes:
     
     EMIT EVENT (with deduplication):
       type: "node.underutilized"
       payload: {
         nodeName: nodeName,
         cpuUtilization: avg_cpu,
         memoryUtilization: avg_mem,
         duration: duration,
         instanceType: instanceType,
         spotPool: spotPool,
         recommendation: "consider_consolidation"
       }
     
     # Debounce: Don't emit again for same node within 5 minutes
   
   Rule 2: Resource Pressure
   IF cpu_utilization > 85% for 2 consecutive readings OR
      memory_utilization > 90% for 2 consecutive readings:
     
     EMIT EVENT:
       type: "node.resource.pressure"
       payload: {
         nodeName: nodeName,
         pressureType: "cpu" | "memory",
         utilization: current_utilization,
         recommendation: "add_capacity_or_right_size_pods"
       }
   
   Rule 3: Frequent Pod Restarts
   IF sum(container_restarts, last_5min) > 3:
     
     EMIT EVENT:
       type: "node.unstable"
       payload: {
         nodeName: nodeName,
         restartCount: count,
         affectedPods: [...],
         possibleCause: "oom" | "spot_instability" | "node_issue"
       }

4. SPOT INTERRUPTION SIGNAL DETECTION:
   
   Monitor EC2 instance metadata endpoint (for spot instances):
   
   Poll: http://169.254.169.254/latest/meta-data/spot/instance-action
   Interval: Every 2 seconds
   
   IF response != 404:
     # Interruption notice received!
     action = json.parse(response)
     
     EMIT EVENT (CRITICAL PRIORITY):
       type: "spot.interruption.imminent"
       payload: {
         nodeName: nodeName,
         instanceId: instanceId,
         instanceType: instanceType,
         action: action.action,  # "terminate" | "stop" | "hibernate"
         time: action.time,
         spotPool: spotPool,
         podsOnNode: getPodCount(),
         priority: "CRITICAL",
         timeToAct: "120 seconds"
       }
     
     # Immediately start graceful pod eviction (handled by separate component)

5. HEALTH CHECKS:
   
   Monitor node health signals:
   - kubelet heartbeat failures
   - Docker/containerd daemon status
   - Disk space < 10%
   - Network connectivity issues
   
   IF any health check fails:
     EMIT EVENT:
       type: "node.health.degraded"
       payload: {...}
```

#### **Decision Engine Core Logic**

```python
class DecisionEngine:
    """
    Main Decision Engine
    Event-driven, pluggable ML models
    """
    
    def __init__(self):
        self.event_bus = EventBus()
        self.model_registry = ModelRegistry()
        self.action_executor = ActionExecutor()
        self.state_store = StateStore()  # Redis for fast state access
        
        # Load models (pluggable)
        self.risk_model = self.model_registry.load("risk_classifier_v1")
        self.savings_model = self.model_registry.load("savings_regressor_v1")
        
        # Subscribe to events
        self.event_bus.subscribe([
            "spot.risk.increased",
            "spot.interruption.imminent",
            "spot.global.interruption.spike",
            "node.underutilized",
            "node.resource.pressure",
            "pod.evicted.spot",
            "capacity.insufficient"
        ], self.handle_event)
    
    def handle_event(self, event):
        """
        Main event handler - routes events to appropriate processors
        """
        # Log event
        logger.info(f"Received event: {event.type}")
        
        # Route to appropriate handler
        handler_map = {
            "spot.risk.increased": self.handle_risk_increase,
            "spot.interruption.imminent": self.handle_imminent_interruption,
            "spot.global.interruption.spike": self.handle_global_spike,
            "node.underutilized": self.handle_underutilization,
            "node.resource.pressure": self.handle_resource_pressure,
            "pod.evicted.spot": self.handle_pod_eviction,
            "capacity.insufficient": self.handle_capacity_shortage
        }
        
        handler = handler_map.get(event.type)
        if handler:
            handler(event)
        else:
            logger.warning(f"No handler for event type: {event.type}")
    
    # ─────────────────────────────────────────────────────────
    # HANDLER: Spot Risk Increase
    # ─────────────────────────────────────────────────────────
    def handle_risk_increase(self, event):
        """
        Triggered when spot interruption rate increases
        Decision: Should we rebalance proactively?
        """
        region = event.payload.region
        instance_type = event.payload.instanceType
        current_rate = event.payload.currentRate
        
        # 1. Get affected nodes
        affected_nodes = self.get_nodes_by_instance_type(
            region, instance_type
        )
        
        if not affected_nodes:
            logger.info("No nodes affected by this risk increase")
            return
        
        # 2. Prepare model input features
        features = self.prepare_risk_features(
            nodes=affected_nodes,
            interruption_rate=current_rate,
            region=region,
            instance_type=instance_type
        )
        
        # 3. Run risk classification model
        risk_scores = self.risk_model.predict(features)
        
        # 4. Aggregate risk assessment
        for node, risk_score in zip(affected_nodes, risk_scores):
            logger.info(f"Node {node.name}: Risk score = {risk_score}")
            
            # Store risk score for trending
            self.state_store.set(
                key=f"risk:{node.name}",
                value=risk_score,
                ttl=3600  # 1 hour
            )
            
            # Decision threshold
            if risk_score > 0.7:  # High risk
                self.make_rebalance_decision(node, risk_score)
            elif risk_score > 0.5:  # Medium risk
                self.make_monitoring_decision(node, risk_score)
        
    def make_rebalance_decision(self, node, risk_score):
        """
        Decide whether to rebalance this node
        """
        node_name = node.name
        spot_pool = node.labels.get("karpenter.sh/nodepool")
        
        # 1. Get pods on this node
        pods = self.get_pods_on_node(node_name)
        
        # 2. Calculate rebalance cost/benefit
        rebalance_analysis = self.analyze_rebalance_impact(
            node=node,
            pods=pods,
            risk_score=risk_score
        )
        
        # 3. Decision logic
        if rebalance_analysis["benefit_score"] > rebalance_analysis["cost_score"]:
            # Rebalance is worth it
            logger.info(f"Decision: REBALANCE node {node_name}")
            
            # Execute rebalance action
            self.action_executor.queue_action({
                "action": "rebalance_node",
                "target": node_name,
                "priority": "high" if risk_score > 0.85 else "medium",
                "reason": f"High spot risk (score: {risk_score:.2f})",
                "strategy": "gradual_drain",  # vs "immediate_drain"
                "deadline": "10 minutes",
                "metadata": rebalance_analysis
            })
            
            # Emit decision event (for observability)
            self.event_bus.publish({
                "type": "decision.rebalance.approved",
                "payload": {
                    "nodeName": node_name,
                    "riskScore": risk_score,
                    "analysis": rebalance_analysis
                }
            })
        else:
            logger.info(f"Decision: MONITOR node {node_name} (not worth rebalancing yet)")
            self.make_monitoring_decision(node, risk_score)
    
    def analyze_rebalance_impact(self, node, pods, risk_score):
        """
        Cost/benefit analysis of rebalancing a node
        """
        # Cost factors
        pod_restart_cost = len(pods) * 0.1  # Each pod restart has a cost
        disruption_cost = sum([
            self.get_pod_criticality_score(pod) for pod in pods
        ])
        
        # Benefit factors
        interruption_probability = risk_score
        potential_data_loss_cost = self.calculate_data_loss_risk(pods)
        recovery_time_saved = 120  # seconds (avoid spot termination recovery)
        
        # Calculate savings projection
        if self.savings_model:
            savings_features = self.prepare_savings_features(node, pods)
            projected_savings = self.savings_model.predict(savings_features)
        else:
            projected_savings = 0.15  # Default 15% savings assumption
        
        # Scoring
        cost_score = pod_restart_cost + disruption_cost
        benefit_score = (
            interruption_probability * 10 +  # High weight on interruption risk
            potential_data_loss_cost * 0.5 +
            (recovery_time_saved / 60) +  # Minutes saved
            projected_savings * 5  # Savings benefit
        )
        
        return {
            "cost_score": cost_score,
            "benefit_score": benefit_score,
            "net_benefit": benefit_score - cost_score,
            "projected_savings_pct": projected_savings,
            "interruption_probability": interruption_probability,
            "affected_pods": len(pods),
            "critical_pods": sum([1 for p in pods if self.is_critical_pod(p)]),
            "recommendation": "rebalance" if benefit_score > cost_score else "monitor"
        }
    
    def prepare_risk_features(self, nodes, interruption_rate, region, instance_type):
        """
        Prepare features for risk classification model
        Model expects: [interruption_rate, hour_of_day, day_of_week, 
                        historical_interruptions, regional_capacity_score]
        """
        from datetime import datetime
        
        features_list = []
        
        for node in nodes:
            # Get historical interruption count for this node
            historical_interruptions = self.state_store.get_count(
                key_pattern=f"interruption:{node.name}:*",
                time_window="24h"
            )
            
            # Get regional capacity score (from AWS Spot Advisor)
            regional_capacity = self.get_regional_capacity_score(region)
            
            # Time-based features
            now = datetime.utcnow()
            hour_of_day = now.hour
            day_of_week = now.weekday()
            
            # Instance characteristics
            instance_size_score = self.get_instance_size_score(instance_type)
            
            # Node characteristics
            pod_count = len(self.get_pods_on_node(node.name))
            node_age_hours = (now - node.created_at).total_seconds() / 3600
            
            features = [
                interruption_rate,           # 0: Current interruption rate
                hour_of_day,                 # 1: Hour (0-23)
                day_of_week,                 # 2: Day (0-6)
                historical_interruptions,     # 3: Past interruptions
                regional_capacity,           # 4: Regional capacity score
                instance_size_score,         # 5: Instance size factor
                pod_count,                   # 6: Number of pods
                node_age_hours,              # 7: Node age in hours
            ]
            
            features_list.append(features)
        
        return np.array(features_list)
    
    def prepare_savings_features(self, node, pods):
        """
        Prepare features for savings regression model
        Model predicts: % savings in next 1 hour if rebalanced
        """
        # Current cost metrics
        current_hourly_cost = self.calculate_node_hourly_cost(node)
        
        # Utilization metrics
        cpu_utilization = self.get_node_metric(node.name, "cpu_utilization")
        memory_utilization = self.get_node_metric(node.name, "memory_utilization")
        
        # Workload characteristics
        pod_count = len(pods)
        total_cpu_requests = sum([self.get_pod_cpu_request(p) for p in pods])
        total_memory_requests = sum([self.get_pod_memory_request(p) for p in pods])
        
        # Alternative instance types available
        alternative_types_count = len(self.get_alternative_instance_types(
            cpu_required=total_cpu_requests,
            memory_required=total_memory_requests,
            region=node.region
        ))
        
        # Spot vs on-demand price difference
        spot_price = self.get_current_spot_price(node.instance_type, node.region)
        ondemand_price = self.get_ondemand_price(node.instance_type)
        price_ratio = spot_price / ondemand_price if ondemand_price > 0 else 1.0
        
        features = [
            current_hourly_cost,         # 0: Current cost
            cpu_utilization,             # 1: CPU %
            memory_utilization,          # 2: Memory %
            pod_count,                   # 3: Pod count
            total_cpu_requests,          # 4: Total CPU requested
            total_memory_requests,       # 5: Total memory requested
            alternative_types_count,     # 6: Alternatives available
            price_ratio,                 # 7: Spot/on-demand ratio
        ]
        
        return np.array([features])
    
    # ─────────────────────────────────────────────────────────
    # HANDLER: Imminent Interruption
    # ─────────────────────────────────────────────────────────
    def handle_imminent_interruption(self, event):
        """
        CRITICAL: AWS sent interruption notice (2-minute warning)
        Must act immediately
        """
        node_name = event.payload.nodeName
        time_to_interruption = event.payload.timeToInterruption
        
        logger.critical(f"IMMINENT INTERRUPTION: Node {node_name} in {time_to_interruption}")
        
        # Immediate action - no ML inference needed, time-critical
        self.action_executor.queue_action({
            "action": "emergency_drain",
            "target": node_name,
            "priority": "critical",
            "deadline": "90 seconds",  # Must complete before interruption
            "reason": "AWS spot interruption notice",
            "strategy": "fast_eviction",  # Bypass graceful drain
            "ignore_pdb": False,  # Still respect PDBs if possible
            "force_after": 90  # Force eviction after 90 seconds
        })
        
        # Record interruption for learning
        self.state_store.increment(
            key=f"interruption:{node_name}:{datetime.now().isoformat()}",
            ttl=86400  # Keep for 24 hours
        )
        
        # Feed to global learning system
        self.event_bus.publish({
            "type": "interruption.confirmed",
            "payload": {
                "nodeName": node_name,
                "instanceType": event.payload.instanceType,
                "region": event.payload.region,
                "az": event.payload.availabilityZone,
                "timestamp": datetime.now().isoformat()
            }
        })
    
    # ─────────────────────────────────────────────────────────
    # HANDLER: Global Interruption Spike
    # ─────────────────────────────────────────────────────────
    def handle_global_spike(self, event):
        """
        Multiple clients reporting interruptions for specific instance type/region
        Proactively mark pool as risky
        """
        region = event.payload.region
        instance_type = event.payload.instanceType
        confidence = event.payload.confidenceLevel
        
        logger.warning(f"Global interruption spike detected: {region}/{instance_type} (confidence: {confidence})")
        
        # 1. Flag pool as risky in state store
        self.state_store.set(
            key=f"risky_pool:{region}:{instance_type}",
            value={"confidence": confidence, "reason": "global_spike"},
            ttl=3600  # Flag as risky for 1 hour
        )
        
        # 2. Find all nodes using this pool
        affected_nodes = self.get_nodes_by_instance_type(region, instance_type)
        
        if not affected_nodes:
            return
        
        # 3. Proactive rebalancing decision
        for node in affected_nodes:
            pods = self.get_pods_on_node(node.name)
            
            # Only rebalance if node has critical workloads
            has_critical_pods = any([self.is_critical_pod(p) for p in pods])
            
            if has_critical_pods or confidence > 0.9:
                logger.info(f"Proactive rebalance: {node.name} due to global spike")
                
                self.action_executor.queue_action({
                    "action": "rebalance_node",
                    "target": node.name,
                    "priority": "high",
                    "reason": f"Global interruption spike (confidence: {confidence:.2f})",
                    "strategy": "gradual_drain",
                    "deadline": "15 minutes"
                })
    
    # ─────────────────────────────────────────────────────────
    # HANDLER: Node Underutilization
    # ─────────────────────────────────────────────────────────
    def handle_underutilization(self, event):
        """
        Node is underutilized - consider consolidation
        """
        node_name = event.payload.nodeName
        cpu_util = event.payload.cpuUtilization
        memory_util = event.payload.memoryUtilization
        
        logger.info(f"Underutilized node: {node_name} (CPU: {cpu_util}%, Mem: {memory_util}%)")
        
        # Get pods on this node
        pods = self.get_pods_on_node(node_name)
        
        # Check if pods can be consolidated elsewhere
        consolidation_possible = self.check_consolidation_feasibility(pods)
        
        if consolidation_possible:
            # Calculate savings from consolidation
            current_cost = self.calculate_node_hourly_cost(
                self.get_node(node_name)
            )
            
            logger.info(f"Consolidation possible. Potential savings: ${current_cost:.2f}/hr")
            
            self.action_executor.queue_action({
                "action": "consolidate_node",
                "target": node_name,
                "priority": "low",  # Not urgent
                "reason": f"Underutilized (CPU: {cpu_util}%, Mem: {memory_util}%)",
                "strategy": "gradual_drain",
                "deadline": "30 minutes",
                "potential_savings": current_cost
            })
    
    # ─────────────────────────────────────────────────────────
    # HANDLER: Resource Pressure
    # ─────────────────────────────────────────────────────────
    def handle_resource_pressure(self, event):
        """
        Node under resource pressure - might need right-sizing or capacity addition
        """
        node_name = event.payload.nodeName
        pressure_type = event.payload.pressureType
        
        logger.warning(f"Resource pressure on {node_name}: {pressure_type}")
        
        # Get pods on node
        pods = self.get_pods_on_node(node_name)
        
        # Analyze: Is this a right-sizing issue or capacity issue?
        analysis = self.analyze_resource_pressure(node_name, pods, pressure_type)
        
        if analysis["cause"] == "oversized_pods":
            # Pods are requesting too much, need right-sizing
            self.event_bus.publish({
                "type": "rightsizing.required",
                "payload": {
                    "nodeName": node_name,
                    "affectedPods": analysis["culprit_pods"],
                    "recommendation": analysis["recommendation"]
                }
            })
        
        elif analysis["cause"] == "insufficient_capacity":
            # Need more capacity
            self.action_executor.queue_action({
                "action": "add_capacity",
                "target": analysis["spot_pool"],
                "priority": "high",
                "reason": f"Resource pressure: {pressure_type}",
                "required_resources": analysis["required_resources"]
            })
```

```python
class ModelRegistry:
    """
    Registry for ML models (ONNX format)
    Supports versioning, A/B testing, and hot-swapping
    """
    
    def __init__(self, model_store_path="/models"):
        self.model_store_path = model_store_path
        self.loaded_models = {}
        self.model_metadata = {}
        
        # Load model configs
        self.load_model_configs()
        
        # Start file watcher for hot-reloading
        self.start_model_watcher()
    
    def load_model_configs(self):
        """
        Load model configurations from JSON files
        """
        config_files = glob.glob(f"{self.model_store_path}/**/config.json", recursive=True)
        
        for config_file in config_files:
            with open(config_file, 'r') as f:
                config = json.load(f)
                model_id = config["model_id"]
                self.model_metadata[model_id] = config
                
                logger.info(f"Registered model: {model_id} (version: {config['version']})")
    
    def load(self, model_id, version="latest"):
        """
        Load a model from the registry
        Returns an inference-ready model wrapper
        """
        # Check if already loaded
        cache_key = f"{model_id}:{version}"
        if cache_key in self.loaded_models:
            logger.debug(f"Using cached model: {cache_key}")
            return self.loaded_models[cache_key]
        
        # Get model metadata
        if model_id not in self.model_metadata:
            raise ValueError(f"Model {model_id} not found in registry")
        
        metadata = self.model_metadata[model_id]
        
        # Determine model file path
        if version == "latest":
            model_file = metadata["latest_version_path"]
        else:
            model_file = f"{self.model_store_path}/{model_id}/versions/{version}.onnx"
        
        # Load ONNX model
        logger.info(f"Loading model: {model_id} (version: {version})")
        model_wrapper = ONNXModelWrapper(
            model_path=model_file,
            metadata=metadata
        )
        
        # Cache loaded model
        self.loaded_models[cache_key] = model_wrapper
        
        return model_wrapper
    
    def start_model_watcher(self):
        """
        Watch model directory for changes and hot-reload
        """
        from watchdog.observers import Observer
        from watchdog.events import FileSystemEventHandler
        
        class ModelFileHandler(FileSystemEventHandler):
            def __init__(self, registry):
                self.registry = registry
            
            def on_modified(self, event):
                if event.src_path.endswith(".onnx") or event.src_path.endswith("config.json"):
                    logger.info(f"Model file changed: {event.src_path}")
                    # Reload model configs
                    self.registry.load_model_configs()
                    # Clear cache to force reload on next use
                    self.registry.loaded_models.clear()
                    logger.info("Model cache cleared - will reload on next use")
        
        observer = Observer()
        observer.schedule(
            ModelFileHandler(self),
            self.model_store_path,
            recursive=True
        )
        observer.start()
        logger.info("Model watcher started")


class ONNXModelWrapper:
    """
    Wrapper for ONNX models with preprocessing and postprocessing
    """
    
    def __init__(self, model_path, metadata):
        import onnxruntime as ort
        
        self.model_path = model_path
        self.metadata = metadata
        
        # Load ONNX session
        self.session = ort.InferenceSession(
            model_path,
            providers=['CPUExecutionProvider']  # Can use GPU if available
        )
        
        # Get input/output names
        self.input_name = self.session.get_inputs()[0].name
        self.output_name = self.session.get_outputs()[0].name
        
        logger.info(f"Model loaded: {metadata['model_id']} (input: {self.input_name}, output: {self.output_name})")
    
    def predict(self, features):
        """
        Run inference
        features: numpy array of shape (n_samples, n_features)
        """
        # Preprocessing (from metadata config)
        if "preprocessing" in self.metadata:
            features = self.preprocess(features, self.metadata["preprocessing"])
        
        # Run inference
        predictions = self.session.run(
            [self.output_name],
            {self.input_name: features.astype(np.float32)}
        )[0]
        
        # Postprocessing
        if "postprocessing" in self.metadata:
            predictions = self.postprocess(predictions, self.metadata["postprocessing"])
        
        return predictions
    
    def preprocess(self, features, config):
        """
        Apply preprocessing transformations
        """
        if config.get("normalization") == "standard":
            # Standardize: (x - mean) / std
            mean = np.array(config["mean"])
            std = np.array(config["std"])
            features = (features - mean) / std
        
        elif config.get("normalization") == "minmax":
            # Min-max scaling: (x - min) / (max - min)
            min_val = np.array(config["min"])
            max_val = np.array(config["max"])
            features = (features - min_val) / (max_val - min_val)
        
        return features
    
    def postprocess(self, predictions, config):
        """
        Apply postprocessing transformations
        """
        if config.get("type") == "classification":
            # Apply softmax if needed
            if config.get("apply_softmax"):
                predictions = self.softmax(predictions)
            
            # Return class probabilities or argmax
            if config.get("return_probabilities"):
                return predictions
            else:
                return np.argmax(predictions, axis=1)
        
        elif config.get("type") == "regression":
            # Clip to valid range
            if "min_value" in config:
                predictions = np.maximum(predictions, config["min_value"])
            if "max_value" in config:
                predictions = np.minimum(predictions, config["max_value"])
        
        return predictions
    
    @staticmethod
    def softmax(x):
        exp_x = np.exp(x - np.max(x, axis=-1, keepdims=True))
        return exp_x / np.sum(exp_x, axis=-1, keepdims=True)
```

```python
"""
ACTION EXECUTOR
Executes decisions made by Decision Engine
"""

class ActionExecutor:
    """
    Executes rebalancing, draining, scaling actions
    Priority queue-based execution
    """
    
    def __init__(self):
        self.action_queue = PriorityQueue()
        self.k8s_client = KubernetesClient()
        self.karpenter_client = KarpenterClient()
        self.state_store = StateStore()
        
        # Start action processor
        self.start_action_processor()
    
    def queue_action(self, action_spec):
        """
        Queue an action for execution
        action_spec: {
            "action": "rebalance_node" | "emergency_drain" | "add_capacity" | "consolidate_node",
            "target": "node-name" | "pool-name",
            "priority": "critical" | "high" | "medium" | "low",
            "deadline": "90 seconds" | "10 minutes",
            "reason": "explanation",
            "strategy": "gradual_drain" | "fast_eviction",
            "metadata": {}
        }
        """
        # Priority mapping
        priority_map = {
            "critical": 0,
            "high": 1,
            "medium": 2,
            "low": 3
        }
        
        action_id = str(uuid.uuid4())
        action_spec["action_id"] = action_id
        action_spec["queued_at"] = datetime.now().isoformat()
        
        # Add to priority queue
        priority = priority_map.get(action_spec["priority"], 2)
        self.action_queue.put((priority, action_id, action_spec))
        
        logger.info(f"Action queued: {action_spec['action']} on {action_spec['target']} (priority: {action_spec['priority']})")
        
        return action_id
    
    def start_action_processor(self):
        """
        Background thread that processes actions from queue
        """
        def process_actions():
            while True:
                try:
                    # Get next action (blocks if queue empty)
                    priority, action_id, action_spec = self.action_queue.get(timeout=1)
                    
                    logger.info(f"Processing action {action_id}: {action_spec['action']}")
                    
                    # Execute action
                    self.execute_action(action_spec)
                    
                except queue.Empty:
                    continue
                except Exception as e:
                    logger.error(f"Error processing action: {e}")
        
        # Start processor thread
        processor_thread = threading.Thread(target=process_actions, daemon=True)
        processor_thread.start()
        logger.info("Action processor started")
    
    def execute_action(self, action_spec):
        """
        Execute a specific action
        """
        action_type = action_spec["action"]
        
        # Route to specific executor
        executors = {
            "rebalance_node": self.execute_rebalance_node,
            "emergency_drain": self.execute_emergency_drain,
            "add_capacity": self.execute_add_capacity,
            "consolidate_node": self.execute_consolidate_node
        }
        
        executor = executors.get(action_type)
        if executor:
            try:
                result = executor(action_spec)
                logger.info(f"Action {action_spec['action_id']} completed: {result}")
            except Exception as e:
                logger.error(f"Action {action_spec['action_id']} failed: {e}")
                # Could implement retry logic here
        else:
            logger.error(f"Unknown action type: {action_type}")
    
    def execute_rebalance_node(self, action_spec):
        """
        Rebalance a node: drain pods and move to alternative instances
        """
        node_name = action_spec["target"]
        strategy = action_spec.get("strategy", "gradual_drain")
        
        # 1. Cordon node (prevent new pods)
        self.k8s_client.cordon_node(node_name)
        logger.info(f"Node {node_name} cordoned")
        
        # 2. Get pods on node
        pods = self.k8s_client.get_pods_on_node(node_name)
        
        # 3. Drain pods based on strategy
        if strategy == "gradual_drain":
            # Respect PDBs, graceful termination
            self.drain_pods_gradually(pods, respect_pdb=True)
        elif strategy == "fast_eviction":
            # Faster, but still respect PDBs if time allows
            self.drain_pods_quickly(pods, respect_pdb=True)
        
        # 4. Wait for pods to reschedule
        self.wait_for_pods_running(pods, timeout=600)  # 10 minutes
        
        # 5. Terminate node
        self.k8s_client.delete_node(node_name)
        logger.info(f"Node {node_name} deleted")
        
        # 6. Karpenter will automatically provision replacement if needed
        # (based on pending pods)
        
        return {"status": "success", "node": node_name}
    
    def execute_emergency_drain(self, action_spec):
        """
        Emergency drain (spot interruption imminent)
        Must complete within 90 seconds
        """
        node_name = action_spec["target"]
        force_after = action_spec.get("force_after", 90)
        
        logger.critical(f"EMERGENCY DRAIN: {node_name} (force after {force_after}s)")
        
        # 1. Immediately cordon
        self.k8s_client.cordon_node(node_name)
        
        # 2. Get pods
        pods = self.k8s_client.get_pods_on_node(node_name)
        
        # 3. Start aggressive eviction
        start_time = time.time()
        
        for pod in pods:
            elapsed = time.time() - start_time
            if elapsed > force_after:
                # Out of time - force delete remaining pods
                logger.warning(f"Force deleting remaining pods on {node_name}")
                self.k8s_client.force_delete_pods(pods, grace_period=0)
                break
            
            # Try graceful eviction with short timeout
            try:
                self.k8s_client.evict_pod(
                    pod.name,
                    pod.namespace,
                    grace_period=10,  # 10 seconds
                    timeout=15
                )
            except Exception as e:
                logger.warning(f"Graceful eviction failed for {pod.name}: {e}")
                # Continue to next pod
        
        # 4. Node will be terminated by AWS shortly
        # Mark node as "terminating" in our state
        self.state_store.set(
            key=f"node:terminating:{node_name}",
            value={"reason": "spot_interruption"},
            ttl=300
        )
        
        return {"status": "emergency_drain_completed", "node": node_name}
    
    def execute_add_capacity(self, action_spec):
        """
        Add capacity to a node pool
        Typically handled by Karpenter automatically, but can be nudged
        """
        pool_name = action_spec["target"]
        required_resources = action_spec.get("required_resources", {})
        
        logger.info(f"Adding capacity to pool: {pool_name}")
        
        # Check if Karpenter is already provisioning
        pending_provisioners = self.karpenter_client.get_pending_provisioners(pool_name)
        
        if pending_provisioners:
            logger.info(f"Karpenter already provisioning for {pool_name}")
            return {"status": "already_provisioning"}
        
        # Trigger Karpenter provisioning by creating demand signal
        # (In practice, Karpenter reacts to pending pods automatically)
        # But we can create a low-priority "placeholder" pod to trigger it
        
        self.k8s_client.create_capacity_placeholder(
            pool=pool_name,
            resources=required_resources
        )
        
        return {"status": "capacity_requested", "pool": pool_name}
    
    def execute_consolidate_node(self, action_spec):
        """
        Consolidate underutilized node
        """
        node_name = action_spec["target"]
        
        # Check if consolidation is still feasible
        pods = self.k8s_client.get_pods_on_node(node_name)
        can_consolidate = self.check_consolidation_feasibility(pods)
        
        if not can_consolidate:
            logger.info(f"Consolidation no longer feasible for {node_name}")
            return {"status": "aborted", "reason": "not_feasible"}
        
        # Execute drain (similar to rebalance but lower priority)
        return self.execute_rebalance_node(action_spec)
```

1. **Event-driven** (no cron dependencies except as fallback)
2. **Pluggable** (models can be hot-swapped)
3. **Scalable** (components can scale independently)
4. **Resilient** (high availability, fault tolerance)
5. **Observable** (all events logged and traceable)
