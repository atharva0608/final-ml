#  Visualization Guide - LightGBM Spot Optimizer

**Last Updated**: January 22, 2026

This guide explains how to read and interpret the visualization dashboards generated by the model training pipeline.

---

## Overview

| Feature Analysis Dashboard | `feature_analysis_dashboard.png` | Feature importance comparison |
| Business Impact Dashboard | `business_impact_dashboard.png` | Business-relevant insights and trends |

This is the **primary dashboard** for evaluating model quality. It contains a KPI summary panel at the top and 6 detailed plots.

### KPI Summary Panel (Top Row)

```
┌─────────────────┬───────────────────┬─────────────────┐
│  REGRESSOR    │ ️ CLASSIFIER     │ ️ CONFIG       │
│ MAPE: X.XX%     │ Recall: XX.X%     │ Threshold: 0.XX │
│ R²: 0.XXXX      │ F1: 0.XXX         │ Test Size: X,XXX│
│                 │ AUC: 0.XXX        │                 │
└─────────────────┴───────────────────┴─────────────────┘
```

#### Regressor Metrics (Price Prediction)

| Metric | What It Means | Target | Color Code |
|--------|---------------|--------|------------|
| **MAPE** | Mean Absolute Percentage Error - how far off predictions are on average | < 1% | Green = Good, Red = Bad |
| **R²** | Coefficient of Determination - how much variance is explained | > 0.99 | Green = Good, Yellow = OK |

#### Classifier Metrics (Risk Detection)

| Metric | What It Means | Target | Color Code |
|--------|---------------|--------|------------|
| **Recall** | % of actual risky periods that were correctly identified | > 90% | Green = Good, Red = Bad |
| **F1 Score** | Harmonic mean of Precision and Recall | > 0.70 | Green = Good, Yellow = OK |
| **AUC** | Area Under ROC Curve - overall ranking quality | > 0.70 | Green = Good, Yellow = OK |

#### Configuration

| Metric | What It Means |
|--------|---------------|
| **Threshold** | Probability cutoff for classifying as "Risky" (optimized for F1) |
| **Test Size** | Number of rows in the holdout test set |

### Row 1: Classifier Plots

#### Plot 1: Confusion Matrix
Shows the actual vs predicted risk classification breakdown.

```
              Predicted
            Safe    Risky
Actual  Safe   TN      FP
       Risky   FN      TP
```

| Cell | Meaning | Impact |
|------|---------|--------|
| **TN** (True Negative) | Correctly predicted Safe |  Good |
| **TP** (True Positive) | Correctly predicted Risky |  Good |
| **FP** (False Positive) | Predicted Risky but was Safe | ️ False alarm |
| **FN** (False Negative) | Predicted Safe but was Risky |  Missed risk! |

**Key Insight**: FN (False Negatives) are the most dangerous - these are risky periods we failed to catch!

#### Plot 2: ROC Curve
Shows the trade-off between True Positive Rate (catching risks) and False Positive Rate (false alarms).

- **Blue Line**: Model performance
- **Red Dashed Line**: Random guessing (baseline)
- **AUC Value**: Area under the curve (higher = better)

**How to Read**:
- Curve close to top-left corner = excellent model
- Curve on diagonal = random guessing
- AUC > 0.7 = acceptable, AUC > 0.8 = good, AUC > 0.9 = excellent

#### Plot 3: Precision-Recall Curve
Shows the trade-off between Precision (avoiding false alarms) and Recall (catching all risks).

- **Blue Line**: P-R trade-off at different thresholds
- **Red Dot**: Optimal threshold point (maximizes F1)
- **Green Dashed Line**: Current precision level

**How to Read**:
- The red dot shows where threshold = optimal F1 balance
- Moving right increases Recall but decreases Precision
- For risk detection, we prefer HIGH RECALL even at cost of precision

### Row 2: Regressor Plots

#### Plot 4: Price Forecast (Last 60 Days)
Time series comparison of actual vs predicted daily average savings.

- **Blue Solid Line**: Actual future savings
- **Red Dashed Line**: Model predictions
- **Gray Shaded Area**: Gap between actual and predicted

**How to Read**:
- Lines should track closely together
- Large gaps indicate prediction errors
- Check for systematic bias (consistently over/under predicting)

#### Plot 5: Error Stability Over Time
Shows how prediction errors change over time.

- **Blue Line**: Mean daily absolute error
- **Shaded Band**: ±1 standard deviation

**How to Read**:
- Flat line = stable performance
- Increasing trend = model degradation (may need retraining)
- Large spikes = unusual market conditions

#### Plot 6: Error Distribution
Histogram showing the distribution of prediction errors.

- **Blue Bars**: Frequency of each error level
- **Red Line**: Mean error
- **Green Line**: Median error

**How to Read**:
- Should be bell-shaped and centered near 0
- Long right tail = occasional large errors
- Mean ≈ Median = symmetric errors (good)
- Mean >> Median = skewed by outliers

## 2.  Feature Analysis Dashboard

Shows which features contribute most to model predictions.

### Plot 1: Regressor Top 10 Features
Horizontal bar chart ranked by importance (gain).

**How to Read**:
- Longer bars = more important features
- Top features drive price predictions
- Look for: lag features, rolling stats, headroom metrics

### Plot 2: Classifier Top 10 Features
Same format for the risk classifier.

**Key Difference from Regressor**:
- Classifier typically values **volatility features** (std_24, std_144)
- Regressor typically values **level features** (lag, min, max)

### Plot 3: Feature Rank Comparison
Side-by-side comparison of feature rankings between models.

- **Green Bars**: Regressor rank (lower = more important)
- **Purple Bars**: Classifier rank

**What to Look For**:
- Features important to BOTH models: `savings_lag_6`, aggregated stats
- Features unique to Classifier: volatility, stress indices
- Features unique to Regressor: recent prices, headroom

## 3.  Business Impact Dashboard

Translates model performance into business insights.

### Plot 1: Savings by Risk Level
Distribution of predicted savings split by risk classification.

- **Green**: Predicted Safe periods
- **Red**: Predicted Risky periods

**What to Look For**:
- Safe periods should have higher, more stable savings
- Risky periods may have wider distribution (uncertainty)

### Plot 2: Risk by Instance Family
Bar chart showing which instance families are predicted as most risky.

**Color Coding**:
-  Red: >30% predicted risky
- 🟠 Orange: 15-30% risky
- 🟢 Green: <15% risky

**Business Action**: Consider avoiding or monitoring high-risk families.

### Plot 3: Top 10 Worst Pools
Instance pools with highest mean prediction error.

**What to Look For**:
- These pools may have unusual pricing patterns
- Consider adding pool-specific features
- May need dedicated models for worst pools

### Plot 4: Temporal Trends (Last 60 Days)
Dual-axis chart showing error and risk percentage over time.

- **Blue Line** (Left Axis): Mean daily error
- **Red Dashed Line** (Right Axis): % of predictions flagged as risky

**What to Look For**:
- Inverse relationship (high risk = high error) suggests model is calibrated
- Parallel trends may indicate external market forces

##  Quick Checklist

When reviewing dashboards, check:

| Check | Target | Action if Failed |
|-------|--------|------------------|
| MAPE | < 1% | Review features, check data quality |
| R² | > 0.99 | Normal for spot prices (high persistence) |
| Recall | > 90% | Lower threshold, add class weights |
| F1 | > 0.70 | Balance precision/recall tradeoff |
| AUC | > 0.70 | Review classifier features, sampling |
| Error Stability | Flat trend | Monitor for drift, schedule retraining |
| Family Risk | No surprise families | Validate against historical incidents |

##  Technical Notes

### Large Data Handling
The visualization module handles millions of rows efficiently:
- **Sampling**: Histograms limited to 100K points
- **Aggregation**: Time series aggregated to daily means
- **Decimation**: Curves downsampled to 200 points
- **Memory**: Explicit cleanup after each plot

### File Locations
Dashboards are saved to:
- SageMaker: `/opt/ml/model/`
- Local: `reports/visualizations/`

### Customization
Modify `src/visualize.py` to add/change plots:
- `plot_performance_dashboard()`: KPI panel + 6 plots
- `plot_feature_analysis_dashboard()`: 3 feature plots
- `plot_business_impact_dashboard()`: 4 business plots
