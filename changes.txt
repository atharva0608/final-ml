### 2. Teaser Savings Calculation (IMPLEMENTED)
**File:** `backend/workers/tasks/discovery.py`

**Function:** `analyze_cluster_potential()` (Lines 26-134)

**Calculation:**
```
Potential Savings = (On-Demand Price - Spot Price) × 730 hours × Count of On-Demand Nodes
```

**Data Sources:**
- On-Demand Price: `pricing_helper.get_ec2_price(region, instance_type)`
- Spot Price: `ec2.describe_spot_price_history()` (real-time)
- Fallback: 40% of On-Demand if API fails

## � TROUBLESHOOTING

### If "Activate Optimization" fails:

1. **Check Backend Logs:**
   ```bash
   docker logs spot-optimizer-backend --tail 100
   ```

2. **Verify Platform Credentials:**
   - `PLATFORM_AWS_ACCESS_KEY` in SystemConfig
   - `PLATFORM_AWS_SECRET` in SystemConfig
   - `PLATFORM_AWS_REGION` in SystemConfig

3. **Verify IAM Permissions:**
   - Trust policy allows `sts:AssumeRole` from platform account
   - External ID matches org ID

4. **Check Cluster CA Data:**
   - `cluster_ca_data` must be stored in database
   - Run discovery refresh if missing
