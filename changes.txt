ATHARVA AI - INTELLIGENT COST OPTIMIZATION INTERFACE
═══════════════════════════════════════════════════════════════════════════

PROJECT OVERVIEW:
Design a cutting-edge, AI-powered Kubernetes cost optimization interface that 
combines real-time risk monitoring, automated rebalancing, and intelligent 
resource management. The interface should feel like a mission control center 
for cluster cost optimization.

PRODUCT NAME: AtharvaAi
TAGLINE: "AI-Driven Cluster Optimization"
POSITION: Main Menu Sidebar → Optimization → AtharvaAi

DESIGN PRINCIPLES:
1. Real-Time First - All data updates live via WebSocket
2. Risk Awareness - Always visible, color-coded risk indicators
3. Intelligent Automation - AI makes decisions, humans supervise
4. Safety Guardrails - Clear warnings before manual overrides
5. Data Transparency - Show WHY decisions are made
6. Performance Optimized - Handle 1000+ nodes smoothly

COLOR PALETTE:
- Primary (AI/Success): #10B981 (Green)
- Risk High: #EF4444 (Red)
- Risk Medium: #F59E0B (Orange)
- Risk Low: #3B82F6 (Blue)
- Neutral: #6B7280 (Gray)
- Background: #F9FAFB (Light gray)
- Surface: #FFFFFF (Cards)
- Accent: #8B5CF6 (Purple - for AI highlights)

- AI Status: Active (green) | Paused (yellow) | Error (red)

- Pending Actions: Count of queued rebalancing actions
  Click to view action queue
  
- Last Update: Time since last data refresh
  Shows connection status to event bus

Animation:
- Status pills fade in on page load (staggered 50ms delay)
- Pills pulse gently when state changes
- Savings counter increments smoothly with number ticker effect

Features:

1. LIVE UPDATES via WebSocket:
   - Rankings recalculate every 30 seconds
   - Position changes animate (rows slide up/down)
   - New entries fade in with highlight effect
   - Risk percentages update with color transition

2. SCORING ALGORITHM (displayed on hover):
   Score = (1 - risk_score) * 0.6 + 
           (1 - price_normalized) * 0.3 + 
           savings_potential * 0.1
   
   Tooltip shows breakdown:
   ┌─────────────────────────────────┐
   │ m5.large (us-west-2a)          │
   │                                 │
   │ Score Breakdown:                │
   │ • Safety:   9.2/10 (92% weight)│
   │ • Cost:     9.5/10 (30% weight)│
   │ • Savings: 15% (10% weight)    │
   │                                 │
   │ Final Score: 9.2/10            │
   │                                 │
   │ Risk Factors:                   │
   │ ✓ Low interruption rate (8%)   │
   │ ✓ Stable last 24h              │
   │ ✓ No recent global spikes      │
   │ ⚠️ Medium utilization in region│
   └─────────────────────────────────┘

3. TREND INDICATORS:
   ↗️ Improving: Risk decreasing or price dropping
   → Stable: No significant change
   ↘️ Degrading: Risk increasing or price rising

4. RANK CHANGE INDICATORS:
   ▲ Moved up in rankings
   ▼ Moved down
   → No change

5. COLOR CODING:
   - Green row border: Low risk (<20%)
   - Yellow row border: Medium risk (20-40%)
   - Red row border: High risk (>40%)
   - Current selection: Gold star + highlight

6. INTERACTIVE ELEMENTS:
   - Hover row: Expands to show detailed metrics
   - Click row: Shows full pool details in modal
   - [Select] button: Opens manual switch confirmation dialog
   - Row drag: Can reorder by priority (custom weighting)

7. FILTERS & SORTING (top of card):
   ┌─────────────────────────────────────────────┐
   │ Filter: [All Regions ▼] [All Types ▼]      │
   │ Sort by: [Score ▼] [Risk ▼] [Cost ▼]       │
   │ Show: [Top 10 ▼] [Top 20] [All]            │
   └─────────────────────────────────────────────┘

Animation:
- Rankings re-sort with smooth transitions
- Rows slide to new positions (300ms ease-out)
- Score changes with number ticker animation
- Risk percentage changes with color fade
