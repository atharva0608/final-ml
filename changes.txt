---

### 1. Optimization Mode Selector

**Placement:** Top of cluster detail

**Data:**
PATCH `/api/v1/clusters/{id}`

**Logic:**
Controls risk ceiling:

* 0.50

---

### 2. Stateless Classification Badge (CRITICAL)

**Placement:** Under cluster name

Badge:

* STATELESS (green)
* STATEFUL (red)
* UNKNOWN (blocked)

**Data:**
`GET /api/v1/clusters/{id}/classification`

**Logic:**
If stateful:
Disable:

* Auto optimization
* Substitute engine
* Rebalancing

---

### 3. Substitute Engine Card (NEW)

**Placement:** Below KPI strip

**Show:**

* State: IDLE / PREWARMING / READY / ACTIVE
* If PREWARMING: countdown
* If ACTIVE: substitute pool + cost drift %

**Data:**
`GET /api/v1/substitute/status/{cluster_id}`

---

### 4. Cooldown Status Widget

**Placement:** Execution panel

**Show:**

* Last switch
* Next allowed switch
* Cooldown duration

**Data:**
`GET /api/v1/cooldown/{cluster_id}`

---

### 5. Circuit Breaker Panel

**Placement:** Below substitute card

**Show:**

* Execution failure count
* Breaker state
* Resume button

**Data:**
`GET /api/v1/execution/status/{cluster_id}`
